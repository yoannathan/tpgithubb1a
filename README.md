# Git & GitHub — Cours pratique

Site statique pédagogique construit à partir du support de formation de Kevin Noël Fonkoua Tatant. Il présente les fondamentaux de Git et GitHub à travers le projet fil rouge **MonSiteWeb**.

## Contenu

- Différence entre Git et GitHub
- Vocabulaire essentiel : dépôt, commit, branche et remote
- Cycle `modifier → vérifier → add → commit → push`
- Commandes de référence
- Parcours de mise en ligne avec GitHub Pages
- Bonnes pratiques pour protéger les secrets

## Utilisation locale

Ouvrir `index.html` dans un navigateur ou démarrer un serveur statique :

```bash
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000>.

## Déploiement

Le site est compatible avec GitHub Pages. Dans **Settings → Pages**, sélectionner la branche `main` et le dossier `/(root)` comme source de déploiement.
