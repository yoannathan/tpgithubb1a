01 · Les fondamentaux

Git et GitHub : deux outils complémentaires

Git travaille sur votre ordinateur. GitHub héberge et partage le dépôt en ligne.

G

Git

Logiciel de gestion de versions qui conserve l’historique de vos fichiers et permet de revenir à un état connu.

  • Historique local
  • Commits et branches
  • Fonctionne hors connexion
GH

GitHub

Plateforme en ligne qui héberge une copie distante du dépôt et facilite la collaboration.

  • Push et pull
  • Issues et Pull Requests
  • Publication avec GitHub Pages
DépôtDossier suivi par Git
CommitInstantané enregistré
BrancheLigne de développement
RemoteDépôt distant

02 · Le cycle essentiel

Modifier → vérifier → enregistrer → publier

Ce cycle simple évite les erreurs et rend chaque évolution lisible.

01

Modifier

Travaillez dans votre éditeur et sauvegardez les fichiers.

02

Contrôler

Utilisez git status et git diff pour inspecter.

03

Préparer

Ajoutez uniquement les fichiers attendus avec git add.

04

Committer

Enregistrez un changement cohérent avec un message clair.

05

Publier

Envoyez l’historique distant avec git push.

04 · Projet fil rouge

MonSiteWeb, de zéro à GitHub Pages.

Créez une page d’accueil avec des sections À propos, Services et Contact. Versionnez-la, développez une fonctionnalité sur une branche, puis publiez le résultat.

Suivre les bonnes pratiques
✓ Créer index.html et style.css
✓ Initialiser Git et produire des commits utiles
✓ Créer une branche pour les Témoignages
✓ Fusionner après vérification
✓ Activer GitHub Pages depuis main
À retenir avant de publier

Ne commitez jamais de mot de passe, clé API, jeton ou donnée privée. Ajoutez .env, les fichiers temporaires et les secrets à votre .gitignore. Un secret déjà publié doit être révoqué : le supprimer dans un nouveau commit ne suffit pas.
